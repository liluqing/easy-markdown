# 调研数据治理

`research/` 保存产品验证、技术 Spike 和迁移实验的原始证据。这里的文件不是产品或技术
决策本身；结论必须回写关联的 REQ、产品文档或 ADR。

## 提交要求

- 记录数据来源、采集日期、负责人、样本选择和使用限制。
- 使用稳定文件名，并从关联 REQ/WORK/ADR 链接到证据。
- CSV 保持 UTF-8、首行为字段名；同一列含义不得在文件中途变化。
- 测试数据使用虚构或已脱敏内容。
- 不提交 Token、Cookie、私有远端地址、个人联系方式或真实客户正文。
- 无法共享的证据只记录安全位置、摘要和复核人，不把本机绝对路径当长期链接。

## 从证据到决策

1. 在 WORK 中预先写明假设、样本和通过标准。
2. 将原始结果保存到本目录，不只粘贴成功截图。
3. 记录异常值、失败与环境限制。
4. 在 REQ 或 ADR 中总结结论并链接原始数据。
5. 更新产品/技术基线；原始数据不替代当前真源。
