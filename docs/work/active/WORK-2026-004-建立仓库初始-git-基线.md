## 7. 风险与阻塞

- 风险：根提交错误纳入文件后不能通过普通工作流隐藏；通过精确清单、逐文件暂存和 tree
  等值检查控制。
- 风险：`core.autocrlf=true` 造成跨平台换行漂移；通过 `.gitattributes` 固定 index 为 LF。
- 风险：根提交前无法记录其 SHA；通过第二个聚焦终态提交保存准确根 SHA 和验证证据。
- 阻塞条件：清单、秘密/异常文件、cached diff、Harness 或 Git 身份任一检查失败。
- 解除人/条件：修正候选内容并重新执行完整闸门；不通过强制或历史改写绕过。
- 解除后的第一步：从文件枚举和 staged manifest 重新开始验证。
