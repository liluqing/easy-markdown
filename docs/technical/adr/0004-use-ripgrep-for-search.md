# ADR-0004：MVP 全文搜索使用 ripgrep

| 字段 | 内容 |
| --- | --- |
| 状态 | Accepted for Spike |
| 日期 | 2026-07-18 |

## 背景

MVP 需要搜索 Markdown/TXT，但不需要复杂相关度排序和结构化查询。文件变化可能来自应用、Agent、Git 或其他编辑器。

## 决策

- 捆绑固定版本 ripgrep Sidecar。
- 使用 JSON 流式输出。
- 只搜索支持的文本扩展名。
- 设置超时、取消、结果数和文件大小上限。
- 不建立 SQLite 搜索索引。

## 后果

正面：

- 搜索结果始终反映磁盘当前状态。
- 无索引同步和损坏问题。
- 实现简单，支持多平台。

负面：

- 缺少相关度排名、中文分词和复杂元数据过滤。
- 超大知识库需要重复扫描。

## 升级条件

代表性 100,000 文件搜索不达标，或产品确认需要结构化检索时，评估 SQLite FTS5 作为可重建索引。
